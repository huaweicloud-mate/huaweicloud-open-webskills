# 分辨率支持矩阵与总体原则

## 总体原则

1. **官网页面**默认支持全尺寸响应适配（任意分辨率自适应）。
   - 如产品特别说明只支持 PC 端，则需设置最小宽度 `1280px`，小于 1280px 出现横向滚动条；
   - 能兼容到更小宽度更优。
2. **管理中心网站**默认只支持 PC 端：设置最小宽度 `1280px`，小于 1280px 出现横向滚动条。
3. 不论页面支持的分辨率范围如何，**任何浏览器宽度下都不允许出现页面变形、元素错位/挤压**。
   - 显示不下时设置最小宽度、出现横向滚动条；
   - **表格属于例外组件**：字段过多时可采用表格内部横向滚动条，但应保证页面整体不出现横向滚动条。

## 实施指引

### PC 端最小宽度
- 只支持 PC 的页面：`html, body { min-width: 1280px; }`（管理台等 >= 1440px 的页面按需设置）。
- 宽度不足时允许出现横向滚动条，禁止内容压缩变形、元素错位/挤压。

### 全尺寸响应适配
- 官网页面默认全尺寸适配：使用流式栅格 + 断点（断点体系见 `huawei-cloud-web-responsive-layout`）。
- 关键宽度建议覆盖：2560、1920、1600、1440、1368、1280、1024、768、375。

### 表格例外规则
- 字段过多的表格：容器 `overflow-x: auto`，表格自身设置合适 `min-width` 保证表头不挤压，内部滚动；
- 页面整体不得出现横向滚动条（表格容器内部滚动除外）。

### 既有问题清单（评审/排查时优先复现）
- 文档站：1600 屏宽下菜单栏与内容区域无间距 → 检查 T 型布局左右栏间距。
- 文档站移动端（< 768px）：文档目录和 8 件套样式错乱 → 全屏布局未适配，需修复或明确降级。
- 实名认证：小屏幕访问页面变形 → 补充 `min-width: 1280px`。
- 工单：1200 / 900 屏宽下「在线提单」标题无左内边距 → 补充内边距。
- 管理台页面：>= 1440px T 型布局支持情况需要排查确认。
