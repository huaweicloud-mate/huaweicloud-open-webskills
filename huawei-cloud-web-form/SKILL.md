# 表单开发 Skill

面向各类网页表单的通用开发规范（推广报名、留资、登录/注册、数据录入、搜索、问卷、配置等）。按以下流程工作，细节参考对应资源文件。

## 工作流

### 1. 明确表单目标与字段
- 先确认表单目标（报名、留资、注册、登录、数据录入、搜索、问卷、配置等）与成功指标，再定字段，只保留必要字段。
- 区分必填/选填、字段类型（文本、手机、邮箱、下拉、单选、多选、文件、隐私勾选）。
- 确认数据接收方：提交接口地址、字段名映射、数据用途，与后端对齐字段名。

### 2. 定义字段校验
- 按 `references/validation-rules.md` 逐字段配置校验规则与错误提示。
- 校验时机：失焦时校验单字段，提交时校验全部字段；错误提示需具体、友好。
- 前端校验只是体验优化，服务端必须做同样校验，规则保持一致。
- 防抖与节流：实时输入校验用防抖（默认 300ms）；提交防连点用按钮禁用 + 请求 token，不用节流（会吞掉合法提交）；高频埋点上报用节流。

### 3. 实现表单 UI
- 原生页面复制 `assets/form-template/`；Vue 3 项目复制 `assets/form-template-vue/SignupForm.vue`，均按需裁剪。示例为推广报名场景，字段与文案替换为实际业务即可。
- 表单元素必须绑定 label，错误提示通过 aria-describedby/role 与输入框关联。
- 提交按钮提供明确文案（如「立即报名」），点击后进入加载态并禁用。

### 4. 接入提交流程
- 按 `references/submission-flow.md` 实现：序列化、加载态、成功/失败反馈、超时处理。
- 防止重复提交：提交中禁用按钮，配合请求唯一 token；以服务端幂等为准。
- 提交成功：显示成功反馈并触发成功埋点（推广场景即转化）；失败时保留已填内容并提供重试。

### 5. 防刷与安全
- 按 `references/submission-flow.md` 实现蜜罐字段、限流、token 校验。
- 前端不出现签名密钥或管理员凭据；文本字段入库前转义，防 XSS/注入。
- 按表单风险分级：登录/注册等涉及账号的启用验证码；普通留资可仅用蜜罐 + 限流；内部后台表单以白名单与权限控制为主。

### 6. 埋点与转化
- 事件命名统一：`form_view`、`form_start`、`field_error`、`submit_click`、`submit_success`、`submit_fail`。
- 提交成功即转化；推广场景页面需透传渠道来源参数（如 utm_source）。注册/登录类表单埋点关注注册转化与登录成功率，数据录入类关注提交完成率；不上报敏感字段。

### 7. 可访问性
- 每个输入控件有可见 label；错误提示用 aria-describedby 关联，输入框错误态用 aria-invalid。
- 支持键盘操作；必填项用 required 标注；文本与背景对比度满足 WCAG AA。

### 8. 上线自检清单
- [ ] 必填与格式校验全部覆盖，错误提示无错别字
- [ ] 手机号等格式符合目标地区规则
- [ ] 重复点击不会产生重复提交
- [ ] 提交成功、业务失败、网络异常、超时均有反馈
- [ ] 蜜罐与限流已生效，服务端完成重复校验
- [ ] 埋点事件在测试环境验证上报成功
- [ ] 隐私政策与同意勾选符合合规要求

## 资源

- `references/validation-rules.md`：各字段类型的校验规则、正则与错误提示，实施校验时读取。
- `references/submission-flow.md`：提交流程、防重复提交、防刷与埋点细则，接入接口时读取。
- `assets/form-template/`：原生 HTML/CSS/JS 表单模板（推广报名示例），可直接复制使用并替换为任意场景。
- `assets/form-template-vue/SignupForm.vue`：Vue 3（`<script setup>`）单文件组件版模板，复制到 Vue 3 + Vite 项目中使用，逻辑与原生版一致。
