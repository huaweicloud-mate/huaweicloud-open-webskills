# 字段校验规则

表单常见字段的校验规则、正则与错误提示。使用前先确认目标地区与业务约束，规则可在此基础上裁剪。

## 通用原则
- 前端校验用于即时反馈，服务端必须重复校验，二者规则保持一致。
- 错误提示直接说明问题与修改方式，不模棱两可。
- 校验触发时机：失焦时校验单个字段，提交时校验全部字段。

## 字段规则

### 姓名
- 必填，1–50 个字符；允许中文、英文、空格与间隔号「·」
- 错误提示：「请输入姓名」「姓名长度需在 1-50 个字符之间」

### 手机号（中国大陆）
- 正则：`^1[3-9]\d{9}$`
- 校验前先去除空格与短横线；输入框限制 11 位数字
- 错误提示：「请输入正确的 11 位手机号」

### 邮箱
- 正则：`^[^\s@]+@[^\s@]+\.[^\s@]+$`
- 提交前转小写
- 错误提示：「请输入正确的邮箱地址」

### 微信号
- 6–20 位，由字母、数字、下划线、减号组成，不能以数字开头
- 正则：`^[a-zA-Z][-_a-zA-Z0-9]{5,19}$`
- 错误提示：「请输入正确的微信号（6-20 位，不能以数字开头）」

### 身份证号（中国大陆）
- 18 位，前 17 位为数字，末位可为数字或大写 X
- 正则：`^\d{17}[\dX]$`
- 展示与日志中脱敏（如 `110***********1234`）
- 错误提示：「请输入正确的 18 位身份证号」

### 公司名称
- 必填，2–100 个字符
- 错误提示：「请输入公司名称」「公司名称长度需在 2-100 个字符之间」

### 自定义文本（留言、需求描述）
- 必填时建议 10–500 字，非必填上限 500 字
- 去除首尾空格；转义 HTML 特殊字符（`<`、`>`、`&`、`"`、`'`）防 XSS
- 错误提示：「需求描述需在 10-500 字之间」

### 下拉 / 单选 / 多选
- 下拉首项为占位项（如「请选择」），占位项不可提交
- 多选需明确最少/最多数量，错误提示：「请至少选择 1 项，最多 3 项」

### 文件上传
- 限制类型与大小（如图片 ≤ 5MB，jpg/png/webp），客户端校验 MIME 与大小
- 上传中显示进度与失败重试

## 隐私合规
- 收集手机号、身份证等个人信息时，页面需提供隐私政策链接与同意勾选
- 未勾选时阻止提交，提示：「请先阅读并同意《隐私政策》」
