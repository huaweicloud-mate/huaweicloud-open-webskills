# 01 全局 Token 校验清单

脚本（`assets/ui-check.js`）覆盖 CSS 声明层；本清单覆盖**语义与结构层**的全局核对项。逐条记录：实测值 / 规范值 / 结论。

## 1. 色彩语义（tokens/colors.md）

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 主要文字 | `#191919`（gray-90），**不是 #000** | error |
| 次要文字 | `#595959`（gray-60） | error |
| 弱化文字 | `#808080`；禁用 `#c2c2c2` | warn |
| 主按钮底 | `#191919`；深底楼层主按钮 `#FFFFFF` | error |
| 次按钮 | 透明底 + 1px 描边 `#595959` | warn |
| 品牌强调红 | `#C7000B`（华为红）；**活动价用 #C7000B，不是 #E02128** | error |
| 错误色 | `#F23030`（error-active 才是 `#C7000B`） | warn |
| 链接/文本按钮 | `#1476FF`，链接激活转 `#595959` | warn |
| 分割线 | `#DBDBDB`（浅灰 3） | warn |
| 页面深底 | `#191919`（页脚、深色楼层） | warn |
| 楼层灰底 | `#F5F5F5`（gray-10）；悬浮 `#FAFAFA`（gray-5） | error |
| 插画配色 | 只用插画色板 `#1476FF / #6CCD06 / #FFAD04` + 12 色，**不混入 UI 色板** | warn |
| 渐变字（通栏广告） | 渐变端点取插画/UI 色板内色值，且须有 `forced-colors` 兜底纯色 | warn |

**易错点**：
- `#000000` 仅允许出现在「全部产品展示」的产品名一层（product-catalog 实测），其余文字应为 `#191919`
- 角标红用 `#F23030`，促销语义的活动价红是 `#C7000B`，两者不可互换

## 2. 字阶场景（tokens/typography.md）

16 档：`10 / 12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 54 / 56 / 60`

| 场景 | 规范字号 | 级别 |
|---|---|---|
| 楼层大标题 | 36（架构图）/ 32 / 28 | warn |
| 通栏广告标题 | 56（1920）/ 48 / 40 三档 | error |
| 卡片标题 | 20（产品/新闻卡）/ 24（架构图一级） | error |
| 正文/描述 | 16；奖项卡正文 12 | error |
| 页签/导航项 | 18（楼层 Tab、锚点 1920 档）；1536 档 16；1280 档 14 | error |
| 辅助/角标 | 12 / 10 | warn |
| **命名错位** | 设计稿 XLarge=48 对应 baseui `large(40)`？——**否：按实测值走，不按 baseui 命名**（设计稿 Large=40、XLarge=48） | info |

## 3. 间距与内容区（tokens/spacing.md）

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 1920 楼层左右 padding | **恒 76**（外框 1752 = 1600 + 76×2） | error |
| 优势楼层例外 | 内容区 1592，左右 padding **164** | error |
| 通栏广告例外 | 内容区 1008 | error |
| 门户（news/blog）内容区 | 1280 | warn |
| 楼层上下 padding | 76（合并相邻灰底楼层时收掉一份，避免双倍留白） | warn |
| **gap 验算** | `(内容区 − n × 卡宽) / (n − 1)` 必须等于声明的 gap，否则卡宽或数量错 | error |
| 4px 栅格 | 所有 gap/padding 是 4 的倍数 | warn |

## 4. 圆角（tokens/shadows-radii.md）

| 元素 | 规范值 | 级别 |
|---|---|---|
| 卡片主力圆角 | 16（信息卡，791 次）或 24（大卡/插画卡/套餐卡，381 次） | error |
| 按钮 | **恒 24，胶囊**——任何高度档都是 24 | error |
| 架构图内容区白卡 | **直角 0**（特征值） | error |
| 小元件/输入框 | 4 / 6 / 8 / 12 | warn |
| 药丸/头像 | 50% | warn |

## 5. 楼层节奏与断点

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 楼层底色节奏 | 深(`#191919`/渐变) → 灰(`#F5F5F5`) → 白 交替；灰底楼层相邻时合并 padding | info |
| 四断点 | 1920 / 1536 / 1280 / 1024，逐档核对卡数与卡宽（见 03-floors） | warn |
| 吸顶层级 | z-index 900（页内导航） | warn |
| 字族 | HarmonyOS Sans 首选，兜底 PingFang SC / Microsoft YaHei | warn |

## 6. 禁止事项（实测依据）

| 禁止 | 依据 | 级别 |
|---|---|---|
| `text-decoration: line-through` | 全库 18,289 节点删除线 0 处；原价靠前缀 + 字号降两档 | error |
| 拿插画当架构图 | 架构图是独立模块（scenario-architecture.md） | warn |
| 优势楼层用白卡 | 灰卡 `#FAFAFA` 配白楼层才是实测组合；灰楼层配白卡是「架构图」的做法 | warn |
| z-index > 900 | level.md 层级上限 | warn |
