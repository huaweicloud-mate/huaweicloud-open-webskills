# 02 组件级校验清单

逐组件核对。格式：`校验项 | 规范值 | 级别 | 出处`。识别到组件后逐条填实测值。

## 按钮（components/buttons.md）

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 高度四档 | 24 / 32 / 40 / 48 | error |
| 圆角 | 恒 24（胶囊），与高度无关 | error |
| 主按钮底色 | `#191919`；深底楼层（通栏广告、黑底）改 `#FFFFFF` 底 + `#191919` 字 | error |
| 次按钮 | 透明底 + 1px `#595959` 描边 | warn |
| 左右 padding | 16 / 24 / 32 / 48 对应四档 | warn |
| hover 态 | 黑/白基 rgba 透明变体（如 `rgba(25,25,25,.04)`） | info |

## 卡片（components/cards.md 及各楼层文件）

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 通用卡圆角 | 16 | error |
| 大卡/插画卡/套餐卡圆角 | 24 | error |
| 卡内 padding 常见档 | 48 / 32 / 28 / 24 | warn |
| **产品推荐卡特征** | 上下 padding **52**、无边框、无按钮；不是通用卡 | error |
| 双卡售前 | 两卡 `788×282`（r16 / pad `32 32 40`）+ gap 24，`788×2+24=1600`；两卡 stretch 等高 | error |
| 卡组 gap 自洽 | `(内容区 − n×卡宽)/(n−1)` = 声明 gap；2→788/24、3→517/24、4→388/16、5→307/16、6→253/16 | error |
| 收起规则 | 数量 > 4 时收起 + 展开开关（套餐规格卡） | info |
