# 03 楼层模块校验清单

识别页面里的楼层后逐个核对。每层先核对「楼层外框 + 内容区」，再核对排布自洽性。

## 通用（先跑每一层）

| 校验项 | 规范值 | 级别 |
|---|---|---|
| 楼层宽 | 1920（断点 1536/1280/1024 逐档核对） | error |
| 左右 padding | 76（优势楼层 164、通栏广告 456→内容区 1008 例外） | error |
| 内容区 | 1600（优势楼层 1592） | error |
| gap 自洽验算 | `(1600 − n×卡宽)/(n−1) = gap` | error |
