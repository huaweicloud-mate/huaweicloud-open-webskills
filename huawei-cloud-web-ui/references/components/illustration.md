# 插画（Illustration）

来源：官网设计稿「5. 插画」「5. 插画✅」两组（10 个变体）+ 插画规范色板（17 条）实测

插画是官网**视觉识别度最高**的元素。本规范分两层：

1. **插画资源规范** —— 颜色、线宽、画布比例，保证不同人画的插画视觉统一；
2. **插画卡版式** —— 插画与标题、描述、按钮组合成卡片的固定结构。

⚠️ 插画**不是**图标（`icon.md`）也不是装饰背景图。它的职责是「用图解释一个业务概念」，必须与同卡文案语义对应。

## 1. 插画规范色（实测，共 17 条）

插画颜色独立于 UI 色彩体系，**不要直接复用 `--por-color-*`**——两者色相接近但用途不同。

### 主色（大面积主体）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `插画-填充色-主色1` | `#1476FF` | 主色：科技蓝，占比最大 |
| `插画-填充色-主色2` | `#6CCD06` | 辅色：绿色，用于「增长 / 安全 / 通过」 |
| `插画-填充色-主色3` | `#FFAD04` | 辅色：橙黄，用于「提醒 / 加速 / 亮点」 |

### 点缀色（小面积高对比）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `插画-填充色-点缀色1` | `#191919` | 深色块、设备外壳、文字 |
| `插画-填充色-点缀色2` | 渐变 | 高亮点缀（需从设计稿取渐变值） |
| `插画-填充色-点缀色3` | `#1D2B43` | 深蓝灰，用于纵深背景 |

### 中性色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `插画-填充色-灰色2` | `#F0F0F0` | 浅灰块、面板底 |
| `插画-填充-灰色3` | `#E6E6E6` | 更浅的层次 |
| `插画-填充色-白色` | `#FFFFFF` | 高光、留白 |
| `插画-线颜色` | `#808080` | 描边线（默认） |
| `插画-线颜色-白` | `#FFFFFF` | 深底上的描边 |

### 灰调点缀（三色一组）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `插画-填充色-点缀黄灰色` | `#FAE396` | 暖调低饱和面 |
| `插画-填充色-点缀蓝灰色` | `#C4E1FF` | 冷调低饱和面 |
| `插画-填充色-点缀绿灰色` | `#DAF2BB` | 自然调低饱和面 |

### 渐变（三条，用于大气氛面）

| Token | 说明 |
| --- | --- |
| `插画-填充色-渐变色1` | 主渐变，多用于大面积背景块 |
| `插画-填充色-渐变色2` | 辅助渐变 |
| `插画-填充色-渐变色3` | 点缀渐变 |

```css
  --por-illu-accent-1: #191919;
  --por-illu-accent-3: #1D2B43;
  --por-illu-gray-2: #F0F0F0;
  --por-illu-gray-3: #E6E6E6;
  --por-illu-line: #808080;

  --por-illu-nature: #DAF2BB;

```

**用色规则**

| 规则 | 说明 |
| --- | --- |
| 主色不超过 2 个 | 一幅插画里主色 1 + 一个辅色，三个主色同时出现会花 |
| 点缀色只占小面积 | 点缀色面积 ≤ 15%，只用于焦点 |
| 灰调只作背景面 | 黄/蓝/绿灰是「低饱和衬底」，不承担语义 |
| 一个楼层插画同风格 | 同楼层多张插画必须同一画法（等距 / 扁平 / 线描），不能混 |

## 2. 画布与比例（实测）

所有插画实例均为 **1.91 : 1**（不是 16:9 的 1.78），这是画布基准比例：

| 使用位置 | 实测画布 | 说明 |
| --- | --- | --- |
| 插画宽卡 / 大卡 | `688 × 360` | 主力尺寸（出现 14 次） |
| 单卡片（中） | `601 × 314` | |
| 插画窄卡 | `556 × 291` | |
| 单卡片（小） | `504 × 264` | |
| 最小卡 | `408 × 213` | 1/4 排布时 |

> 制作规范：**画布按 1.91:1 出图**，用 SVG（优先）或 2x PNG。放置时按容器宽度等比缩放，`object-fit: contain`，**不要裁切**——插画四周留白是构图的一部分。

```css
.por-illu {
  display: block;
  width: 100%;
  aspect-ratio: 1.91 / 1;
  object-fit: contain;
}
```

## 3. 插画卡版式

### 结构

```
┌──────────────────────────────────┐
│  padding 48                       │
│  ┌────────────────────────────┐  │
│  │                            │  │
│  │        插 画（1.91:1）      │  │  ← 插画区，等比
│  │                            │  │
│  └────────────────────────────┘  │
│         ↕ gap 32                  │
│  优势标题2            28px #191919│  ← 标题（单行）
│         ↕ gap 16                  │
│  描述文字，最多两行……             │  ← 描述（≤2 行）
│         ↕ gap 24                  │
│  [ 立即购买 ]  [ 了解详情 ]       │  ← 按钮组
└──────────────────────────────────┘
```

### 三种卡片规格（实测）

| 类别 | 尺寸 | 圆角 | padding | 内部 gap | 底色 |
| --- | --- | --- | --- | --- | --- |
| `插画窄卡` | `652 × 648` | `24px` | `48px` | `32px` | `#FFFFFF` / `#FAFAFA` |
| `插画宽卡` | `916 × 648` | `24px` | `48px` | `32px` | `#FAFAFA` |
| `2列之1`（双列卡） | `784 × 656` | `24px` | `48px` | `32px` | `#FAFAFA` |

窄卡与宽卡**高度都是 648**，只差宽度——同排混排时天然等高。

### 文字规格（实测）

| 元素 | 字号 | 颜色 | 约束 |
| --- | --- | --- | --- |
| 卡片标题 | `28px` | `#191919` | 单行，超出截断 |
| 描述 | `16px` | `#595959` | 最多 2 行，超出省略号 |
| 按钮 | 见 `buttons.md` | — | `Medium`（40）或 `Small`（32） |

### 按钮组（实测）

| 位置 | 按钮组尺寸 | 按钮尺寸 | 组内 gap |
| --- | --- | --- | --- |
| 大卡 | `256 × 40` | `Medium`（40） | `16px` |
| 小卡 | `216 × 32` | `Small`（32） | `8px` |

## 5. 场景图 vs 概念图

仓库里有两类插画，用法不同：

| 类型 | 特征 | 用途 | 是否可用照片替代 |
| --- | --- | --- | --- |
| **概念插画** | 扁平 / 等距，用品牌色 | 解释抽象能力（隔离、计费、多端） | ❌ 不可 |
| **场景图** | 架构示意、产品界面示意 | 说明「怎么用」 | ❌ 不可（改用 `architecture` 类组件） |

照片（4K~7K 摄影图）只用于 Banner 与通栏广告背景，**不能替代插画卡里的插画**。

## 6. 无障碍

| 项 | 要求 |
| --- | --- |
| `alt` | 必填，描述插画表达的**业务含义**（如「三个可用区相互隔离」），不写「插画」「图片」 |
| 纯装饰插画 | `alt=""` + `aria-hidden="true"` |
| 文字对比度 | 插画上的叠加文字 ≥ 4.5:1；深色插画上文字配 `text-shadow` 或半透明底衬 |
| 动效 | 不做自动播放的插画动画；如加，遵循 `prefers-reduced-motion` |

## 7. Do / Don't

**Do**

- ✅ 画布按 `1.91:1` 出图，放进去按宽度等比缩放
- ✅ 同楼层多张插画同一画法（比如都等距）、同一色系
- ✅ 插画卡内「插画 → 标题 → 描述 → 按钮」顺序固定，gap 固定
- ✅ 插画与文案语义一一对应（标题说「秒级计费」，图就画计费）

**Don't**

- ❌ 不要把插画裁成 16:9 或 1:1 塞进固定高度容器（会切掉四周留白，构图散掉）
- ❌ 不要在插画上用 UI 语义色（`--por-color-function-error` 等），会破坏品牌插画的统一感
- ❌ 不要一幅图里同时用三个主色
- ❌ 不要用插画代替产品截图或架构图——语义不同，用户会误读
- ❌ 不要给插画加投影/描边等 UI 效果，插画自带层次
