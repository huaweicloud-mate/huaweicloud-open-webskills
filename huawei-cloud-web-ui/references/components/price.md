# 价格

来源：Tiny PortalUI price 规范

## 实例

使用下面列出的类可以创建不同尺寸的价格。

```html
<div class="por-price por-price-s">
  <div class="por-current-price"><i class="por-price-symbol">¥</i><span>4221.00</span><i class="por-price-unit">/年起</i></div>
</div>

<div class="por-price">
  <div class="por-current-price"><i class="por-price-symbol">¥</i><span>4221.00</span><i class="por-price-unit">/年起</i></div>
</div>

<div class="por-price por-price-l">
  <div class="por-current-price"><i class="por-price-symbol">¥</i><span>4221.00</span><i class="por-price-unit">/年起</i></div>
</div>
```

## 官网价格区版式（实测）

`por-price` 只给三个尺寸类，实际售价卡的价格区有一套固定排布：**现价 24px + 原价 14px**，两者在同一行、基线不对齐、靠 padding 调。

### 三种形态

| 形态 | 价格行尺寸 | 现价 | 后缀 / 原价 | 卡尺寸 |
| --- | --- | --- | --- | --- |
| **原价** | `243 × 36` | `24px` `#191919` `¥1,000` | `14px` `#191919` `/月，此价格仅为实例价格` | `388 × 124` |
| **活动价** | `176 × 36` | `24px` **`#C7000B`** `¥1,000` | `14px` `#191919` `原价¥2,303.76` | `388 × 124` |
| **加价购（展开）** | 同上 | 同上 | 上方叠规格选择区 | `388 × 350` |

价格区固定 `padding: 32px`，行到按钮的纵向 `gap: 16px`，按钮固定 `120 × 40` 次要按钮（`r24`、左右 `padding 32`）。

### 现价 + 原价的排布

```
┌─────────────────────────────────┐
│ ¥1,000  ┌──────────────┐        │  ← 24px 现价 #C7000B
│         │原价¥2,303.76 │        │  ← 14px #191919，块内 padding 10/4
│         └──────────────┘        │
│         ↕ gap 16                 │
│ [ 立即购买 ▾ ]                   │  ← 120×40 次按钮
└─────────────────────────────────┘
```

- 现价与原价块之间 `gap: 8px`，**底部对齐**（两者都 `36` 高）。
- 原价块 `94 × 36`，内 `padding: 10px 4px`、`gap: 10px`（为将来放"省 ¥xxx"标签预留）。
- 现价用 `#C7000B`（`color-error-active`），**不是** `#E02128`——促销红比错误红深一档。

### ⚠️ 原价不划线

实测全库 18,289 节点中，文本装饰只有两种状态：`UNDERLINE`（218 处，**全部是正文里的链接**）与无装饰。**删除线 0 处**。

设计稿里的"原价¥2,303.76"是 `14px / #191919 / 无装饰`，靠**"原价"二字前缀 + 字号降两档**表达，不靠 `line-through`。

```css
/* 对：靠前缀 + 字号 */
.por-price-origin {
  font-size: 14px;
  color: #191919;
  padding: 10px 4px;
}
/* 错：加删除线（设计稿没有这个用法） */
.por-price-origin--strike { text-decoration: line-through; color: #8C8C8C; }
```

如果业务方坚持要删除线，视为**超出规范的定制**，需要单独评审，不要写进通用样式。

### 加价购（附加选购）

加价购是价格区下方的一段可选商品勾选区，`加价购=开` 时卡高从 `274` 涨到 `350`（**+76**）。

```
388 × 350   padding 32   gap 16
├─ 规格区 324 × 258
│   ├─ 规格行 324 × 26      ← 文本 324×22 + 分隔线 324×1
│   ├─ 规格行 324 × 26      ← 行间 gap 24
│   ├─ …（4 行时总高 226）
│   └─ 展开按钮 16 × 16
└─ 加价购复选区 324 × 44   gap 8
    ├─ 复选项 324 × 18      ← 16×16 复选框 r4 + 标签，gap 8
    └─ 复选项 324 × 18
```

| 状态 | 卡高 | 说明 |
| --- | --- | --- |
| 加价购关 | `274` | 只有价格 + 按钮 |
| 加价购开，规格全铺开 | `350` | 2 个复选项全展示 |
| 加价购开，规格收起 | `300` | 只留 1 行规格摘要 + 展开按钮 |

- 规格超过 4 行时折叠，用 `16 × 16` 的展开/收起图标（不是文字链接）。
- 复选框 `16 × 16`、圆角 `4`、`1px` 描边；**不用开关（switch）**——这里是多选。
- 一排 1 个时卡宽 `800`，一排 2 个时 `788`，一排 4 个时 `388`；价格区宽度随之变，但 `padding 32` 不变。
