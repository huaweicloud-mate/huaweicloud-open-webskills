# 滚动条

来源：Tiny PortalUI scrollbar 规范

## 实例

使用下面列出的类可以创建不同样式的滚动条。

```html
<div class="por-scrollbar-s" style="height: 100px; overflow: auto">
    <p>内容...</p>
</div>

<div class="por-scrollbar-m" style="height: 100px; overflow: auto">
    <p>内容...</p>
</div>

<div class="por-scrollbar-m por-scrollbar-dark" style="height: 100px; overflow: auto; background-color: #000">
    <p>内容...</p>
</div>
```

## API 指导

### class

| class | 描述 |
| --- | --- |
| `por-scrollbar-s` | 小容器滚动条 |
| `por-scrollbar-m` | 大容器滚动条 |
| `por-scrollbar-dark` | 深色背景下滚动条 |
