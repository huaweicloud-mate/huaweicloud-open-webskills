## 产品图标

使用 `class="icons-product-md [name]"` 的方式引用。

需先引用：
```html
<link rel="stylesheet" href="https://res-static3.huaweicloud.com/content/dam/cloudbu-site/archive/china/static/v2_resources/css/product-icons.css">
```

| 图标名 | class |
| --- | --- |
| ecs | `icons-product-md ecs` |
| apilist | `icons-product-md apilist` |
| aad | `icons-product-md aad` |
| ... | ... |

> 产品图标以官方 `product-icons.css` 为准，可按需取用具体产品名。
